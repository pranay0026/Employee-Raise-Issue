# Employee Raise Issue — ServiceNow

A ServiceNow-based employee issue management solution that provides a centralized self-service portal for employees to raise workplace-related issues such as payroll discrepancies, access problems, infrastructure requests, and HR-related queries.

## Key Features

* Custom scoped **Employee Center** application
* Custom **Employee Raise Issue** table
* Standardized issue fields and auto-numbering
* **UI Policies** for dynamic form behavior
* **Category → Subcategory** field dependency
* **Record Producer** for issue submission
* Custom **Service Portal**
* Custom **Service Portal Widgets**
* Client-side redirection to the Record Producer
* End-to-end testing and validation

## Project Flow

Employee → Service Portal → Custom Widget → Record Producer → Employee Raise Issue Table
